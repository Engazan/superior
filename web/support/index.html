Connect your phone

  1. Install and open Superior desktop on your computer. Keep it running and connected to the internet.
  2. Open Mobile access on the desktop, enable the connection and create a pairing QR code.
  3. On your phone, choose Pair desktop. Scan the code, or paste the pairing JSON if you prefer not to allow camera access.
  4. Check the displayed relay address and desktop identity before confirming. Open a workspace and select a terminal or Chat.

Pairing codes expire after five minutes. Generate a fresh code if the previous one has expired. Treat a code like a password: it grants access to your desktop workspace.

When something does not connect

The desktop appears offline

Make sure the computer is awake, Superior is running, and Mobile access is enabled. Both devices need internet access to the configured relay. Reopen the mobile app to reconnect; it does not maintain a background connection.

The QR code is rejected or pairing has expired

Create a new code on the desktop. If the phone's pairing was revoked or its replay counter was lost, remove the old pairing and pair again. Confirm that you are using the intended relay.

A message did not receive confirmation

Check the terminal or conversation before sending again. An interrupted connection can leave delivery uncertain. Superior keeps unacknowledged drafts and does not automatically replay uncertain terminal input.

Chat or a newer feature is unavailable

Update both the desktop and mobile apps. Native chat currently requires a compatible Codex CLI installed and signed in on your desktop. Claude and other terminal agents continue to use the terminal view.

An approval must be opened on the desktop

Mobile displays bounded recent excerpts. If an approval is too large to show completely, open the full request on your desktop before deciding. Full conversation history is also available there.

Remove a device safely

First revoke the phone in the desktop's Mobile access panel. Then remove the saved desktop from the phone's Settings menu. Forgetting it on the phone alone does not revoke its relay authorization.

Clear saved drafts before removing the pairing. Desktop conversations and project files are separate. See the privacy policy for retention details and how to request removal of relay records.

Help us reproduce the issue

Include your mobile and desktop app versions, iOS or Android version, computer operating system, the steps you followed and the exact error message. A redacted screenshot can help.

Do not send source code, full logs or terminal output unless needed and reviewed for secrets. For a security issue, email us privately rather than posting a public issue.
